# DELETE /nodes/{node}/certificates/custom

| Name | Type | Required | Description |
|---|---|---:|---|
| node | string | yes | The cluster node name. |

## Request parameters

| Name | Type | Required | Description |
|---|---|---:|---|
| restart | boolean | no | Restart pveproxy. |
